# TP API REST — squelette (L3, ITUniversity)

Décompressez ce dossier à la racine d'un projet CodeIgniter 4 (4.5 ou plus récent).
Les instructions complètes, le contrat de l'API et les questions sont dans l'énoncé.

- `app/Controllers/Api/LivresManuel.php` : niveau 3, étape A (à compléter)
- `app/Controllers/Api/Livres.php` : niveau 3, étape B (à compléter)
- `app/Models/LivreModel.php`, migration et seeder : fournis
- `app/Config/Routes_extrait.php` : routes à recopier dans `app/Config/Routes.php`
- `public/niveau2/` : client JSONPlaceholder, niveau 2 (à compléter)
- `public/client/` : client de recette de votre API (fourni, ne pas modifier)
